Design System

Bảng tra token và component. Phần CSS bên dưới chép từ src/app/globals.css — sửa token trong CSS thì nhớ sửa tay file này cho khớp, nếu không bảng sẽ nói sai.

File tĩnh, không phải route, không nằm trong public/ — người dùng không truy cập được. Mở trực tiếp từ ổ đĩa.
